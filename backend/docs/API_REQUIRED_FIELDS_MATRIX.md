## Compatibility rule

Changing a `REQUIRED` master entry to optional is backwards compatible for established clients that continue supplying a valid value, but enables new omissions. It can still be a server/database breaking change if a stored procedure, `NOT NULL` column, FK, report, external payload or direct dereference remains. Completely removing any field from a public request/response is a contract-breaking change unless a versioned endpoint/response is retained.
