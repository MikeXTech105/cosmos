## What is still not verified or not supported

1. **Actual SQL gate:** no configured `COSMOS_PRODUCTION_INTEGRATION_CONNECTION_STRING`, SQL service, sqlcmd or Docker runtime was available. No bundled appsettings credentials, live catalog or provisioner were used. All 39 migration scripts still need guarded execution/binding/repeatability checks, followed by real JWT/company/RBAC/concurrency/rollback and stock/financial journeys in the disposable test catalog.
2. **Existing baseline failures:** the three employee tests and the unchanged dispatch-import lint finding remain separate existing behavior; the suite is not described as entirely green.
3. **Financial-credit contract:** one financial credit consumes one whole accepted physical return against one actual confirmed bill line. Existing returns spanning multiple bills remain a reconciliation boundary; automatic splitting or rewritten history is not implemented.
4. **Source evidence:** unresolved units/openings, stale demand, negative RM stock, inactive historical mappings, unmatched PO/cost/actor evidence and blank vendor details are not invented. CSV/TSV imports are one-tab exports with explicit original row positions, at most5000 source cells and bounded serialized evidence; native XLSX/ZIP parsing and unreadable canvas visuals are not claimed.

The corrected code is reviewable and the independent checks above have run. A statement that every production scenario is 100% complete would still be inaccurate until the actual SQL execution gate and real source exceptions are resolved.
