## Required-field change protocol

For each row, **make optional** means changing the cited rule and request nullability, guarding service use, then reviewing every repository parameter and SQL procedure/column/FK named by the module ledger. **Remove completely** additionally removes the request/response member, mappings, procedure parameter and SQL schema/report/integration use after a compatible deprecation release. The risk and module-specific dependency path are documented under `docs/required-fields/`.
